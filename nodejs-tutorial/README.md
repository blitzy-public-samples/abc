# Node.js + Express Tutorial

A minimal [Express.js](https://expressjs.com/) web server that exposes two `GET`
endpoints returning plain-text greetings. It lives inside the
**ABC: System for Sequential Logic Synthesis and Formal Verification** repository
as a fully self-contained tutorial under `nodejs-tutorial/`.

> **Repository note.** The surrounding repository is the Berkeley **ABC: System
> for Sequential Logic Synthesis and Formal Verification** — a C/C++ Electronic
> Design Automation (EDA) toolkit that ships **no** pre-existing Node.js server.
> This `Hello world` tutorial was therefore **newly created**, not migrated. It
> is fully isolated under `nodejs-tutorial/` and does **not** affect the ABC
> build (GNU Make, CMake, or Bazel) or its CI. You never need to edit anything
> under `src/` or any C/C++ build file to use this tutorial.

## Prerequisites

- **Node.js `>= 18`** — matches the `engines.node` field in `package.json`.
- **npm** — bundled with Node.js; used to install dependencies and run scripts.

## Installation

```bash
cd nodejs-tutorial
npm install
```

`npm install` reads `package.json`, downloads `express@^5.2.1` and its
dependencies into `node_modules/` (git-ignored), and writes/updates
`package-lock.json` (committed to source control for reproducible installs).

## Running the server

```bash
npm start
# equivalently:
node server.js
```

The server listens on `http://localhost:3000` by default and prints the
listening URL to the console.

### Configurable port

The listening port is read from the optional `PORT` environment variable and
defaults to `3000`. To run on a different port:

```bash
PORT=4000 npm start
```

## Endpoints

| Method | Route | Response |
| --- | --- | --- |
| GET | `/` | `Hello world` |
| GET | `/good-evening` | `Good evening` |

Both endpoints return their response as plain text, byte-for-byte.

## Quick test

With the server running (in a separate terminal), exercise both endpoints:

```bash
curl -s localhost:3000/            # -> Hello world
curl -s localhost:3000/good-evening # -> Good evening
```

## Project layout

- `package.json` — npm manifest: declares `express@^5.2.1`, the `start` script, and the `engines.node >= 18` constraint.
- `server.js` — Express application entry point: creates the app, registers both routes, and listens on `PORT` (default `3000`).
- `package-lock.json` — generated by `npm install`; pins the exact dependency tree for reproducible installs (committed).
- `README.md` — this tutorial.
- `node_modules/` — installed dependencies created by `npm install` (git-ignored; not committed).
